# Visual direction

This short note records the design boundary for the personal site refresh.

- Primary blue-grey: `#274C5E`, aligned with the current CV and LinkedIn visual identity.
- White / near-white surfaces, thin rules, low elevation, restrained radius.
- No orange accent system, glassmorphism, oversized hover motion, or decorative emoji as structural UI.
- System fonts first; Chinese and English typography should remain stable without depending on external font delivery.
- Content hierarchy remains more important than card effects: current role, research/technical focus, selected work, archive.
- Mobile navigation remains compact and horizontally scannable.

This file is deliberately about presentation only. It does not authorize new profile claims or broader disclosure of private research or enterprise work.
